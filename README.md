# 서버 식당 · 백엔드 첫걸음

백엔드 기초 개념 16가지를 식당 비유로 배우는 학습 사이트예요. 비전공자와 초등학생도 이해할 수 있는 눈높이로 썼어요.

- **개념 메뉴판**: 서버와 클라이언트, HTTP, API, 데이터베이스, 인증, 캐시 등 16개 개념을 그림과 비유로 설명
- **단어 카드**: 62개 용어를 카드로 뒤집으며 외우기
- **주문 퀴즈**: 45문제, 틀린 문제는 오답 전표에 자동 저장
- **주방 게임**: 상태 코드·메서드 스피드 게임, 단어 짝 찾기

공부 기록은 브라우저(localStorage)에 저장돼요. 그림은 Google Gemini로 만들었어요.
